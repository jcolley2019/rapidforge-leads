**Spend disclosure.** Because the brief said to run `npm test` once at the start and I ran it twice (the second time to capture the full log), the suite spent real money twice: Opus (Builder Brief ×2 tests, Analyst ×2), Sonnet 5.5 (Sales Summary, Design), Haiku (Design Brief) — tests run against `MemoryStore`, so no `usage_events` row exists to quantify it; from the agents' measured per-call costs (Part 5) the estimate is **≈ 30–60¢ per full run, ≈ $1 total**. Fix is stub 3a.
